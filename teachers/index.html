For teachers

Never run a simulation before? Start here.

Every simulation on this site comes with a facilitator guide, a student brief and a marking rubric — all printable, no PDF needed. This page gets you from "never done this" to running your first session.

Run your first simulation: a 30-minute playbook

1. Pick a simulation

Browse the library and match one to a topic you're already teaching.

2. Read the guide

Each simulation page has a facilitator guide: timing, roles, scoring and debrief questions.

3. Hand out the brief

Print or share the student brief so the class knows the rules before you start.

4. Run and debrief

Open the simulation on any device, play the rounds, then use the rubric to grade.

Same console, no app to install — open it on whatever device is in the room.

Prompt packs

Some simulations are AI-run rather than browser-run. For these, the simulation page gives you a copy-paste prompt pack: paste it into any free AI chat (ChatGPT, Gemini, Claude) and it runs the simulation for you, with a no-AI fallback if your students can't access one.

Faculty training

Free online workshops on teaching with simulations are in preparation. To request one for your department, write to hey@aiprof.org.in.
